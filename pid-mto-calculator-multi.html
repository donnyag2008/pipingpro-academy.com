P&ID MTO Methodology
Instruments: Count by tag type (FT, PT, TT, LT, FCV, PCV, etc.)
Equipment: List with nozzle count (pumps, vessels, HX, columns)
Lines: Line number, size, schedule, insulation class, fluid service
Fittings / Specialties: Spectacle blinds, strainers, sample points, vents/drains
Area grouping aggregates all drawings within the same area name. The By Area view shows subtotals per area plus a project grand total. Duplicate line numbers or tags across drawings within the same area are flagged — verify boundary conditions before using totals for procurement.
