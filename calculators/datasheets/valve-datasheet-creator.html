Special notes

How the datasheet is derived

Pipe class → material chain. The pipe class (PMS) defines the body material, trim, bolting grade, gasket type, end connection, and pressure rating. The Creator reads the pipe class definition and auto-populates every material field.

Size → configuration. For ball valves: floating ball for NPS ≤ 4", trunnion-mounted for NPS ≥ 6" per API 6D. Operator type follows: lever for small sizes, gear for large.

Service → features. Fire-safe (API 607), anti-static, anti blow-out stem, and position indicator are added based on service type. NACE MR-0175 notes are generated automatically for sour service.

Temperature → seat. RTFE soft seat is limited to 120°C. When max service temperature exceeds this, the special notes include the metal seat clause.

PMS upload format

Your Excel, CSV, or Word file should include columns for:

• Pipe Class — e.g. 1CC1P01, 3SD0P01

• Rating — e.g. 150, 300, 600

• Body Material — e.g. ASTM A216 WCB, ASTM A351 CF8M

• Trim — e.g. SS Type 316, UNS S31254 6Mo

• Bolting — e.g. A193 Gr.B7M / A194 Gr.2HM

• Gasket — e.g. Graphite, Spiral wound

• End Connection — e.g. RF, RTJ, BW

• Sour — Y/N or Yes/No

Column headers are auto-detected. If auto-detection fails, you can manually map each column. For Word files, the tool extracts the largest table in the document. All processing is done in your browser — no data is sent to any server.
