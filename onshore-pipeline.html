Calculation Appendices
App-1Wall Thickness Calculation
LIVE
Per B31.4/B31.8. Hoop stress, calculated vs selected WT, D/t ratio, acceptance criteria. One sheet per pipeline segment × location class.
Calculator: Wall Thickness Calculator
App-2Pipeline Combined Stress Calculation including Anchor Force
DEV
Hoop, longitudinal (4 load cases), Von Mises equivalent stress, available bending margin, minimum elastic bend radius (in multiples of OD), hydrotest stress check, and anchor force for both thermal cases.
Calculator: Combined Stress & Bending Radius Calculator
App-3Upheaval Buckling Analysis
LIVE
Dr. K. Peters / 3R method. Compressive restraining force, buckling length, uplift resistance from soil, allowable overbend angle for 5 burial depth cases. Elastic vs cold/field bend classification.
Calculator: Upheaval Buckling Calculator
App-4Buoyancy and On-Bottom Stability Analysis
PLANNED
Pipeline weight vs displaced water. Three conditions: installed (dry soil backfill), installed (submerged soil), construction (empty, no backfill). FOS ≥ 1.1. Additional counterweight if required.
Calculator: Buoyancy / On-Bottom Stability Calculator
App-5Buried Pipe Soil Interaction
LIVE
ALA 2001 methodology. Axial soil spring, lateral bearing capacity, vertical uplift/bearing, pipe-soil force-displacement curves for restrained and unrestrained sections.
Calculator: Buried Pipe Soil Interaction Calculator
Data Cascade

Design data is entered once in the report body (Section 4). The same inputs — pipe OD, material grade, design pressure, temperatures, soil properties — automatically cascade to all five appendix calculators. Wall thickness from App-1 feeds into Combined Stress (App-2), which feeds into Upheaval Buckling (App-3) and Buoyancy (App-4). One set of inputs, one consolidated output.

Delivery Format — All Sections
Specifications (Section 01)

Format: Word .docx template
How it works: Structured ToC → each section has an empty box with grey placeholder example text → user deletes/replaces with project data

Design Reports (Section 02)

Format: Word .docx report + calculator appendix
How it works: Report body: Introduction, Design Data, Methodology, Results, Recommendations (fillable) → linked calculator generates appendix with detailed calculation sheets

Mechanical Design Report (Section 03)

Format: Word .docx report + 5× calculator appendices
How it works: Single report body with design data entered once → cascades to all 5 calculator appendices → auto-assembled into one consolidated document (Saudi Aramco 2616-ENG style)
