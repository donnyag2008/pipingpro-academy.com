📋Engineering Disclaimer

    
For preliminary sizing and verification. This tool implements published hand-calculation methods (ALA 2001; Peng, Pipe Line Industry, 1978). The beam-on-elastic-foundation bend solution is a conservative idealisation assuming a rigid non-rotating corner and elastic-perfectly-plastic springs. Rigorous evaluation of restrained buried pipe — non-linear soil behaviour, cable action, large displacement and combined load cases — requires a non-linear pipe-soil finite element analysis. Results must be reviewed by a competent pipeline stress engineer against the governing code and project specification.

Soil restraint springs — ALA Appendix B

    

      

        
Axial (friction), Tu

        
πDαc + πDH·γ̄·½(1+K₀)·tanδ [F/L]

        
Lateral (horizontal), Pu

        
NchcD + Nqhγ̄HD [F/L]

        
Vertical uplift, Qu

        
NcvcD + Nqvγ̄HD [F/L]

        
Vertical bearing, Qd

        
NccD + Nqγ̄HD + Nγγ̄D²/2 [F/L]

        

        

          H = depth to pipe centreline = C + D/2  ·  γ̄ = effective unit weight

          δ = fcφ, interface friction angle (fc from coating)  ·  α = adhesion factor (curve fit, c in ksf)

          Nch, Nqh = horizontal bearing factors (closed-form fits, fn. of H/D, φ)

          Ncv = 2(H/D) ≤ 10 ; Nqv = (φ/44)(H/D) ≤ Nq (shallow burial)

          Nq = eπ·tanφtan²(45+φ/2) ; Nc = (Nq−1)cotφ ; Nγ = e(0.18φ−2.5)
        

      

    

    

      
DirectionYield displacement Δ (representative)

      
Axial Δt3 mm dense sand · 5 mm loose sand · 8 mm stiff clay · 10 mm soft clay

      
Lateral Δp0.04(H + D/2), capped 0.10–0.15 D

      
Uplift Δqu0.01–0.02 H sand (≤0.1 D) · 0.1–0.2 H clay (≤0.2 D)

      
Bearing Δqd0.1 D granular · 0.2 D cohesive

    

    
Springs are bi-linear (elastic–perfectly-plastic). Axial springs use backfill properties; lateral/vertical generally use native soil. The lateral secant stiffness K = Pu/Δp feeds the bend (beam-on-elastic-foundation) solution.

  


  

    
Restrained longitudinal stress — ALA §7 / B31.4 §403, B31.8 §833

    

      

        
Hoop stress
Sh = pD/2t

        
Restrained longitudinal
SL = νSh − EαΔT (− = compressive)

        
Equivalent (Tresca)
Se = |Sh − SL|

        

        

          Hoop check: Sh ≤ F·SMYS (B31.4 F = 0.72; B31.8 F by location class)

          Combined check: Se ≤ 0.9·SMYS  ·  ΔT = T₂ − T₁
        

      

    

    
Don't conflate SL with the anchor force. SL drives the code stress check; the potential expansion force F = A[(0.5−ν)Sh + EαΔT] (which adds the pressure end-force from the unrestrained side) drives the virtual anchor length and movement.

  


  

    
Virtual anchor & movement at a bend — Peng (1978)

    

      

        
Potential expansion force
F = A[(0.5−ν)Sh + EαΔT]

        
Virtual anchor (free end, Q=0)
L₀ = F/f ; y₀ = F²/2AEf

        
Bend resistance
Q = C − √(C²−F²), C = F + βAEf/K

        
Beam-on-elastic-foundation
β = (K/4EI)¼

        
Bend movement / moment
y = Qβ/K ; M = Q/2β ; Sb = M/Z

        

        

          f = axial friction per unit length = Tu  ·  K = lateral stiffness = Pu/Δp

          A = metal area · I, Z = section properties · total movement ∝ F², inversely ∝ f
        

      

    

    
The guided-cantilever / beam-on-elastic-foundation model assumes a rigid non-rotating corner and elastic springs — it overestimates the moment (conservative for the bend) while underestimating deflection. Use it for screening; confirm governing cases with non-linear pipe-soil FE.

  


  

    
Earth / live load & ring response — ALA §3–4

    

      

        
Prism earth load
Pv = γC (above water table)

        
Live load (Boussinesq)
Pp = 3Ps/2πC² · [1/(1+(d/C)²)]2.5

        
Ovality (modified Iowa)
Δy/D = DlKP / (E·Ieq/R³ + 0.061E′)

        
Through-wall bending
σbw = 4E(t/D)(Δy/D)

        
Ring buckling (critical)
Pc = √(32 Rw B′ E′ E·Ieq / D³)

        
Support coefficient
B′ = 1/(1 + 4e−0.065(C/D))

        

        

          C = cover to top · P = Pv + F′·Pp · Ieq = t³/12 per inch · R = D/2

          Rw = 1 − 0.33(hw/C) · FS = 2.5 (C/D>2) or 3.0 (C/D<2)

          Acceptance (App. A): σbw < 0.5σy · ring compression < 0.5σy · ovality ≤ ~3% (API RP-1102)
        

      

    

    
For steel with D/t < 100 and σy > 30 ksi, ALA notes sidewall crushing and ring buckling are rarely governing — these checks mainly matter at road/rail crossings, very shallow cover, or large heavy surface loads.
