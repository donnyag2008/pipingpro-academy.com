Engineering Notes
Average end-area: V = Σ (A₁+A₂)/2 · L — always valid for any spacing. Prismoidal (Simpson's): V = (d/3)[A₀ + 4·Σodd + 2·Σeven + Aₙ] — valid only for equal spacing with an odd number of stations.
End-area slightly over-reads on concave runs. Swell/bulking factors vary with soil type and compaction.
For preliminary engineering use only. Verify against survey data and project earthwork specifications before use in any quantity, procurement or claim.
📚 Methods and code references for sectional earthwork volumes. For full worked examples, visit PipingPro Academy courses.
Average End-Area Method
V = Σ [ (Aᵢ + Aᵢ₊₁) / 2 × Lᵢ ]
Aᵢ, Aᵢ₊₁ = cross-section areas at consecutive stations
Lᵢ = distance (chainage) between the two stations
The workhorse method for trench and excavation quantities. Works for any station spacing. It slightly over-estimates volume where the run is concave between sections; the prismoidal method corrects this.
Prismoidal (Simpson's 1/3) Method
V = (d/3) × [ A₀ + 4(A₁+A₃+…) + 2(A₂+A₄+…) + Aₙ ]
d = constant station spacing
n = number of intervals (must be even → odd number of sections)
More accurate for solids whose area varies smoothly. Requires equal spacing and an odd number of cross-sections. Where conditions are not met the calculator falls back to the average end-area total.
Trapezoidal Trench Area
A = (b + s·h) · h   (symmetric side slopes)
b = trench bottom width   h = depth   s = side slope (H : 1 V)
Top width = b + 2·s·h  ·  s = 0 for vertical (shored) walls
Side-slope selection follows the soil's safe angle of repose and the governing excavation safety code. Common battered slopes range s = 0.5 to 1.5; vertical faces require shoring/trench boxes.
Swell / Bulking Factor
Loose volume = In-situ (bank) volume × (1 + swell%)
1 m³ = 1.30795 yd³  ·  1 yd³ = 27 ft³
Soil swells when excavated. Indicative bank → loose swell: sand 10–15%, common earth 20–30%, clay 30–40%, rock 50%+. Use project-specific factors for haulage and disposal quantities.
