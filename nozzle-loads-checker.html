Nozzle Load Allowables by Equipment Type
API 610 (Pumps): Combined load index = √(Fres² + Mres²) / allowable ≤ 1.0
API 610 Table 4 gives individual force/moment allowables per nozzle size.
Combined check: Σ(Fi/Fallow,i) ≤ 1.0  (resultant basis)

API 617 (Compressors): Similar resultant check; allowables typically 2× API 610.
API 661 (Air Coolers): Nozzle loads per nozzle connection size from Table.
WRC 107/297 (Vessels): Local shell stresses at nozzle junction — σm ≤ Sm, σb ≤ 1.5Sm
All piping stress engineers must confirm nozzle loads are within allowables before issuing for construction. Loads from the Caesar II or ROHR2 output are compared against the equipment manufacturer's certified allowable nozzle loads — which may be higher than API table values for specific equipment designs.
