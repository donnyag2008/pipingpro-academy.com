Combined Equivalent Stress & Elastic Bend Radius
Fully-restrained biaxial (Von Mises) check per ISO 13623:2017 Cl. 6.4.1.2 — Appendix B1 method
ISO 13623:2017Von Mises

Upheaval Buckling Analysis
Buried pipeline download / uplift-resistance check per OTC 6335 (Palmer, 1990) — Appendix C1 method
OTC 6335PalmerBuried
Design equations
Tel = (Pi·Ai − µ·σh·As) + E·α·As·(T2 − T1)  (effective expansion load)
Wr = [1.16 − 4.76·√(EI·Wte/δ)/Tel] · Tel · √(δ·Wte/EI)  (OTC 6335 Eq.12)
q = H·D·ρb·g·(1 + f·H/D)  (uplift resistance, OTC 6335 Eq.13)
Stable when total download Q = Wto + q ≥ Wr (download required)
This module uses the simplified OTC 6335 (Palmer) download / uplift-resistance method as issued in Appendix C1 — effective force via exact Poisson term (µ·σh·As) and soil uplift from backfill mass density. For a fuller screen — DNV-RP-F110 (Peters) allowable-imperfection, Schaminée / Pedersen peak uplift, Cambridge mobilisation and the tri-linear soil model — use the dedicated Upheaval Buckling Calculator in the suite.

📚 Theory, formulae and code references for this calculator. Methodology aligned with the FEED-stage mechanical design of the 18″ liquid pipeline (WP-1+WP-2+WP-3 to CPF). For worked examples, see the PipingPro Academy courses.
Design Basis
Pressure containment (ISO 13623): t = Do·(Pid−Pod)/[2·SMYS·fh·ft + (Pid−Pod)]
Hoop stress: σhp = (Pid−Pod)·(Do−t)/(2t)
Longitudinal (restrained): σL = µ·σhp ; σEA = E·α·(Tc−T) ; σT = σL + σEA
Von Mises equivalent: σeq = √(σhp² − σhp·σT + σT²) ≤ feq·ft·SMYS
Elastic bend radius: Sb1 = feq·ft·SMYS − σeq ; Rcur = E·Do/(2·Sb1)
Upheaval download (OTC 6335 Eq.12): Wr = [1.16 − 4.76·√(EI·Wte/δ)/Tel]·Tel·√(δ·Wte/EI)
Uplift resistance (OTC 6335 Eq.13): q = H·D·ρb·g·(1 + f·H/D)
External collapse (DNV-ST-F101): (Pe − Pmin) ≤ Pc / (γm·γsc)
Propagating buckle: Ppr = 35·fy·αfab·(t/D)^2.5
