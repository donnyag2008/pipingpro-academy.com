Project-specific screening criteria. Select a built-in profile or create your own. Rules are evaluated top-to-bottom within each category; the line takes the most onerous result across all matching rules. Changes are saved to your browser and applied immediately to the Calculator.

Profile details

How rules work. Each rule specifies conditions (min/max size, min/max temperature, service, equipment prefix, two-phase) and an output class (C1, C2, C3, NC). When a line is assessed, every rule is tested. The line takes the highest (most onerous) class from all matching rules. A line that matches no rule defaults to NC.

Method

Every rule in the active criteria profile is tested against the line data. The line takes the most onerous (highest criticality) result. Rules are grouped into five categories: Size-only (pipe diameter thresholds), Size + Temperature (combined diameter and temperature conditions), Two-phase flow (applied when 0 < vapour% < 100), Equipment connectivity (matching From/To tags against equipment prefixes), and Service-based (matching fluid service codes). A line matching no rule defaults to NC. The fluid-service code is read from characters 10–12 of the line number unless manually overridden.

Built-in profiles.
EPC Generic — a twelve-criterion screening method representative of typical EPC LDT procedures. Size thresholds at 2″/16″/24″, high-temp thresholds at 200°C (≥6″) and 280°C (≥2″), low-temp at −50°C and −101°C, plus equipment connectivity for boilers, compressors, heaters, pumps, reactors, turbines, and air coolers.

SAES-L-120 / Saudi Aramco — criteria from the Saudi Aramco Engineering Standard SAES-L-120 Piping Flexibility Analysis, as implemented on Khursaniyah Gas Plant (Bechtel/Technip JV, K78-L-RE-551950). Three criticality categories (C1, C2, C3) with thresholds at 6″/260°C and 16″/121°C for C1, sour gas (≥4″), sour crude (≥12″), relief systems, slugging, and detailed equipment connectivity rules.
